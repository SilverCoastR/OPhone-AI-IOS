# OPhone AI for iOS

**iPhone과 iPad용 오픈 소스 앱 범위 AI 에이전트 런타임.**

[English](README.md) · [简体中文](README.zh-CN.md) · **한국어** · [日本語](README.ja-JP.md)
</div>

OPhone AI for iOS는 Android 버전의 이식 가능한 기능을 SwiftUI로 다시 작성한 프로젝트입니다. DeepSeek, OpenAI 호환 API, Claude Messages API, ChatGPT Web, 로컬 대화, 지속 작업, 이벤트, 내장 브라우저, HTTPS, 비공개 파일, JavaScript 유틸리티, 메모리 및 감사 로그를 제공합니다.

iOS 버전에는 다른 앱을 제어하는 Accessibility, Root, 임의 Shell 기능이 없습니다. 에이전트는 OPhone AI 자체의 브라우저, 네트워크, 파일, 프로그램, 메모리 및 작업 런타임만 자동화합니다.

GitHub Actions는 macOS에서 테스트하고 서명되지 않은 IPA를 아티팩트로 만듭니다. 설치 가능한 IPA에는 Apple Developer 인증서와 Provisioning Profile이 필요합니다. 자세한 내용은 [Build and signing](docs/BUILD_AND_SIGNING.md)을 참조하세요.
