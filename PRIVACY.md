# Privacy

OPhone AI stores API conversations, task state, events, memory, programs, workspace files, settings, and audit records on the device. Provider API keys are stored in iOS Keychain and are sent only to the endpoint configured for that provider.

When anonymous app-open telemetry is enabled, the app sends a random per-installation identifier, Apple hardware identifier, device family, iOS name/version, app version/build, language, and region to the project telemetry endpoint. It does not send conversation content, prompts, tool output, files, memory, browser history, account credentials, or API keys. The switch is available in Settings.

Messages sent through a model API are processed under that provider's terms and privacy policy. ChatGPT Web is a website session governed by the website's policies. A remote provider catalog supplies configuration data only.
